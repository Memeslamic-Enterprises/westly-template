# Needs you

Decisions and actions only the owner can take, shown in the app's Needs You tab with
answer buttons. One `## <question> (added YYYY-MM-DD[, by YYYY-MM-DD])` per entry, 1-3
context lines, optional `options: A | B | C`. Resolved → delete the entry + journal it.
Due within 48h and still open → that's the one case for a ping.
